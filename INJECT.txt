EXPIRY-Kit — MT Manager se inject (6 steps)
============================================

CLASS NAME (unique — Voidstack ke saath conflict NAHI):
  Lcom/expirykit/update/ExpiryKit;

STEP 1 — versions.txt me line (naya app inject = bas ye)
----------------------------------------------------------------
https://github.com/officialsycronix/Expiry-Kit/blob/main/versions.txt
me line add karo (agar naya app hai):

  <package.name>=<versionCode>

Dex ka VERSION_URL already set hai (sab apps me same dex chalega).
Per-app rebuild ki zarurat NAHI.

Package name: aapt2 dump badging app.apk | grep package

STEP 2 — Dex count
------------------
APK → View → kaunse classes*.dex hain? Sabse bada number → naya dex = next number.
(rename: classes10.dex, classes11.dex... jo free ho)

STEP 3 — Logo + dex add
------------------------
  assets/ → modkit_logo.jpg   (agar pehle se hai to SKIP)
  root → classesN.dex (next number)

STEP 4 — Smali 1 line (koi EK — Application ya Activity)
--------------------------------------------------------
Application:
  invoke-static {p0}, Lcom/expirykit/update/ExpiryKit;->install(Landroid/app/Application;)V

Activity (safe — dono alag):
  invoke-static {p0}, Lcom/expirykit/update/ExpiryKit;->attach(Landroid/content/Context;)V

.locals/.registers MAT badlo (agar naya parameter add ho raha ho).

STEP 5 — Sign + install
-----------------------
Sign → purana uninstall → naya install.

========================================
DUAL DIALOG (startup + update ek saath)
========================================
Voidstack ModKit (startup) ka class:
  Lcom/voidstack/modkit/ModKit;      ← unchanged, koi conflict nahi

Expiry-Kit (update) ka class:
  Lcom/expirykit/update/ExpiryKit;   ← unique

Dono ek hi onCreate me chal sakte hain — 2 alag invoke-static lines:
  invoke-static {p0}, Lcom/voidstack/modkit/ModKit;->install(...)   <- startup
  invoke-static {p0}, Lcom/expirykit/update/ExpiryKit;->attach(...) <- update

Dex dono ka alag number pe (jaise classes9 = voidstack, classes10 = expiry).
Logo same assets/modkit_logo.jpg use kar sakte dono (file ek hi).

========================================
DIALOG KAB DIKHEGA (per-app independent):
========================================
  versions.txt me uski line ka value  >  app versionCode  -> FORCED dialog
  value <= versionCode / line missing / 0                 -> normal
  offline                                                  -> normal (blocked nahi)

NAYA APP INJECT (daily flow):
  1. dex+logo+smali inject (dex same for all apps)
  2. versions.txt me uski line add = current versionCode  -> git push

UPDATE RELEASE:
  1. naya APK (manifest versionCode bada hua)
  2. versions.txt me SIRF USKI LINE badlo -> git push
  3. purane users me dialog ON, baaki apps safe
